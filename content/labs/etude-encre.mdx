## 整体结构

全部效果发生在一个片段着色器里：全屏两个三角形，逐像素计算颜色。JS 侧只负责传四个 uniform——时间、分辨率、平滑后的鼠标位置、搅动强度。没有纹理，没有第三方库。

## Domain warp：让噪声"流"起来

单层 fbm 噪声是静态的云雾感，墨的流动感来自三层嵌套采样：

1. 第一层 `q = fbm(p + t)`——基础场，随时间缓慢漂移。
2. 第二层 `r = fbm(p + 3.2q + t)`——用第一层的值扭曲采样坐标。
3. 最终 `f = fbm(p + 3.0r)`——再扭一次。

每层都以不同速度、不同方向被时间推动，叠出来的就是墨在水里晕开的缠绕感。这一手法出自 Inigo Quilez 的 domain warping 经典配方。

## 分层上色

拿到标量场 `f` 之后，用一串 `smoothstep` 把它切成纸色 → 淡晕 → 墨色 → 深沉四档，依次 `mix`。深色档额外乘了一层独立的 fbm，让浓墨处出现颗粒状的沉淀。最后加一点逐帧变化的噪点，模拟纸纹。

## 交互：旋涡注入

鼠标位置映射进噪声空间后，对每个像素计算到鼠标的向量 `dm`，叠加一个垂直于它的切向偏移：

```glsl
p += vec2(-dm.y, dm.x) / max(md, 0.05) * exp(-md * 1.6) * uStir;
```

`exp(-md * 1.6)` 让旋涡随距离指数衰减，`uStir` 由 JS 侧的"能量"驱动——鼠标速度越快能量越高，停下后按 0.94/帧 衰减，所以搅动会慢慢平息，而不是突兀地停住。

## JS 侧的平滑

鼠标不直接用原始坐标，而是每帧向目标位置插值 7%（`m.x += (tx - x) * 0.07`）。视觉上旋涡像有惯性的笔尖，跟在指针后面。
