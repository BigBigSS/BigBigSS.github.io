## 文字如何进入 GPU

WebGL 自己不会排版。做法是先在一张 2048×1024 的离屏 Canvas 2D 上用 `fillText` 画好文字，再整张上传为纹理。着色器里按 contain 规则把这张 2:1 的纹理居中放进任意比例的画布。

有个容易踩的坑：页面字体是异步加载的，首帧可能用后备字体的度量渲染。所以监听 `document.fonts.ready`，字体就绪后把纹理重画一遍。

## 涟漪畸变

对每个像素计算到鼠标的距离 `d`，采样坐标叠加一个径向偏移：

```glsl
float rip = sin(d * 28.0 - uT * 3.2) * exp(-d * 4.5);
vec2 duv = dir * rip * 0.022 * uAmp;
```

`sin(d·28 - t·3.2)` 是从圆心向外传播的波，`exp(-d·4.5)` 让它快速衰减——只有指针附近的字在晃。另外叠了两条低频正弦让整幅文字始终有轻微的呼吸感，不动鼠标时也不是死的。

## 红色残影

同一张纹理采样两次：一次用正常偏移 `duv`，一次用放大 2.6 倍的偏移。两次 alpha 相减的差值区域，就是"字被拖开"的部分，填上朝纸色混过的墨红色。黑色字压在残影之上，看起来像字下面垫了一层没对齐的红版——印刷套色错位的效果。

## 能量驱动

涟漪振幅 `uAmp` 不是常数：鼠标快速划过时 JS 侧累积能量，`uAmp = 0.3 + energy * 2.6`，慢慢移动只有微澜，快速扫过才会掀起大浪。能量按帧衰减，画面自己会静下来。
